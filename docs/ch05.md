# 第5章　競技を支えたチーム、機体、運営基盤

666チームと2,056台が同じ大会で競うには、個々のロボット性能だけでなく、機体を入手・改造する経路、規則、訓練、充電、修理、結果記録が必要になる。WHRGの競争単位はチームだが、その背後には大学、企業、メーカー、共通プラットフォーム、運営設備が重なる。

## 5.1 チームとプラットフォームの関係

| チーム／事例 | 所属・編成 | 使用プラットフォーム／支援 | 競技上の意味 |
|---|---|---|---|
| <span lang="zh">清华火神队</span> | 清華大学 | Booster T2共通機体 | 同じハードウェア上で知覚・戦術・連携を比較 |
| RoboRoos | 豪州3大学の共同チーム | 加速進化の機体・技術支援 | 国外チームが中国製機体を開発基盤に利用 |
| ブラジルチーム | 5つのRoboCupチームを統合 | 加速進化の機体・技術支援 | 既存の競技ソフトウェアを別の共通機体へ適合 |
| GMO Robots | 日本企業、大学との技術関係も報道 | Unitree G1を二次開発 | メーカー直営ではない利用チームの陸上出場 |
| 武大智元聯合チーム | 武漢大学と智元の合同 | OmniHand O10、大学側アルゴリズム | 機体提供と制御開発を分担した粉末計量 |
| 北京人形系二次開発チーム | 31大学・49チーム | 天工シリーズ | 一つの機体系列へ多数の開発主体が参加 |

5対5サッカーの共通機体は、ハードウェア差を小さくし、チーム側のソフトウェアと調整を前面に出した。国外チームへの機体・技術支援は、独自機体を輸送・保守できない参加者にも競技への入口を作った。陸上や実環境タスクでは各チームが異なる機体を使うため、結果には機構、制御、運用の全てが入る。[[1]](#ref-1)[[2]](#ref-2)[[3]](#ref-3)

公式結果の主体はあくまでチームである。所属組織は人材と開発環境を持ち、メーカーは機体を製造し、支援者はハードウェアや訓練を提供する。同じ名称が複数の役割に現れる場合も、その関係を一つに畳まない。第4章のメダル台帳とメーカー系列集計が一致しないのは、この構造による。

## 5.2 大学、企業、共同チーム

国内参加には157社と200の大学・研究機関が含まれた。公式結果には、北京人形ロボットイノベーションセンターと河南科技学院、北京舞蹈学院と智元、武漢大学と智元のような共同名が並ぶ。大学は認識・制御アルゴリズムと学生チームを、企業は機体、部品、整備、実装経験を持ち寄った。[[4]](#ref-4)

共同開発の効果が見えやすいのがデクスタラスハンドである。粉末計量では智元のOmniHand O10を武漢大学チームが制御し、27秒で目標量へ合わせた。電動工具組立ではLinker Handを使う<span lang="zh">灵心巧手</span>が、完全自律で5分間に18本を締め、17本を得点にした。機体名だけでは、誰が認識、計画、制御、競技調整を担ったかは分からない。[[5]](#ref-5)[[6]](#ref-6)

## 5.3 規則と訓練が比較条件を作る

規則は一度に公表されたのではない。組織委員会は4月に最初の26種目、6月に第二陣の試行版、7月に総則と実環境タスクの解説を公開した。チームは規則の更新に合わせ、制限時間、自律条件、介入減点、設備寸法へソフトウェアと機体を調整した。[[7]](#ref-7)[[8]](#ref-8)[[9]](#ref-9)

障害走と実環境タスクには予約訓練があり、開幕直前には公式訓練も行われた。ドア、棚、家電、工具、商品、障害物は配置そのものが入力になる。事前に同等設備で試す時間は、認識モデルの調整、把持位置の確認、安全停止の検証に使われる。[[10]](#ref-10)[[11]](#ref-11)

| 基盤 | 大会での役割 | 技術的な効果 |
|---|---|---|
| 段階公開された規則 | 種目、採点、自律条件を定義 | 結果の測定条件をそろえる |
| 予約・公式訓練 | 本番設備または同等設備へ接続 | 認識・動作・安全を事前調整 |
| 共通機体・ハードウェア支援 | 機体調達の障壁を下げる | ソフトウェア差を比較しやすくする |
| 結果公告と更正 | 順位、記録、運用方式を保存 | 後から結果を再集計できる |

## 5.4 2,056台を動かす裏方

「ロボットの家」には200台の充電キャビネット、約100の固定充電位置、保管区、24の修理ステーションが用意された。競技間の短い時間に、バッテリー交換、関節や外装の点検、ソフトウェア更新、故障修理を回すための設備である。[[12]](#ref-12)

デクスタラスハンド専門種目には、指定ハードウェアを利用するための支援策も公表された。[[13]](#ref-13) サッカーの共通機体と同様、これは参加者全員を同一条件にするというより、機体調達に競争が吸収されすぎないよう、評価したい制御課題へ入口を作る仕組みだった。

公式サイトは競技別の結果をPDFや画像で順次公開し、家庭、ホテル、消防では更正も行った。細分化された公告は個別結果を追える一方、全種目の機械可読表は提供されず、横断集計には再構成が必要だった。この記録基盤があったからこそ、チーム単位の159メダル枠を作り、企業系列の宣伝値と分けて読めた。[[14]](#ref-14)

WHRGの生態系は、メーカーが完成品を見せる展示会とも、大学だけの競技会とも異なる。共通機体でソフトウェアを競う種目、独自機体で統合性能を競う種目、大学と企業が役割を分担する合同チーム、運営側の訓練・整備設備が同居した。競技結果は、その接続が本番の制限時間で機能したかを測る統合試験でもあった。
