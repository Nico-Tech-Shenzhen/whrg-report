# 2500時間超の大会データ

WHRG 2026がメダル以外に残したと発表した最大の成果は、準備・訓練と正式競技から集めた「世界人形机器人运动会全量数据集」である。2026年8月26日の閉幕時に共同発表され、2500時間を超えるデータを含むと説明された。[[1]](#ref-1)[[2]](#ref-2)

## 発表された規模

| 項目 | 発表値 |
| --- | ---: |
| 総時間 | 2500時間超 |
| 収集段階 | 訓練・準備 + 正式競技 |
| 応用場面 | 12 |
| 作業 | 44 |
| skill | 100超 |
| 細分化task | 1万超 |

12応用場面はデータセットの分類であり、大会プログラムの21场景赛とは別の数である。どの競技、Team、機体、期間をどこまで含めて「全量」としたかを示すmanifestは確認できていない。

## 含まれると発表された情報

新华社の説明では、データは原始センサ層、意味注釈層、task軌跡層から成り、次の情報を含む。[[2]](#ref-2)

- 多視点の映像
- 関節運動情報
- ロボット本体・機体状態
- taskの実行結果
- 失敗例と境界条件
- 意図・動作の意味ラベル
- 多視点の物体認識・検出annotation
- 長時間にわたる操作軌跡
- 非構造環境での動的な外乱

競技の成功例だけでなく、失敗や境界条件まで残るなら、競技データは学習、評価、故障分析、長時間taskの研究に使える可能性がある。大会中の動作が表彰と映像だけで消えず、次の開発サイクルへ戻るという構想である。ただし、これは発表された内容の分析であり、実ファイルを検査した結論ではない。

## 共同発表者と役割の限界

共同発表者として次の7主体が挙げられた。[[1]](#ref-1)

| 主体 | 公開情報から確認できる役割 | 確認できないこと |
| --- | --- | --- |
| 赛迪研究院 | 共同発表者 | 保有量、収集・annotationの担当範囲 |
| 北奥集团 | 共同発表者、会場・運営関係 | データ保管・配布の実務担当 |
| 北京人形机器人创新中心 | 共同発表者、Robot provider | 提供データ量、annotation担当 |
| 智元机器人 | 共同発表者、Robot provider | 提供データ量 |
| 银河通用 | 共同発表者、场景赛参加・Robot provider | 提供データ量 |
| 万境千寻 | 共同発表者 | collector、contributor、annotatorの別 |
| 星海图 | 共同発表者、Robot provider | WHRGデータへの具体的な寄与量 |

「共同発表」は、各主体が同量を収集した、annotationした、保管する、配布責任を負う、という意味ではない。智元、银河通用、北京人形が訓練から競技までの動作データを開放する合意に達したという二次報道はあるが、Team別・機体別の寄与manifestはない。[[3]](#ref-3)

## このデータを使えるか

2026年10月10日時点の結論は、**Announced（発表済み）だが、第三者の検証可能な取得経路は監査した公開情報から確認できない**、である。アクセス状態、RoboMIND・AgiBot Worldとの運用比較、必要な公開要素は「データは実際に使えるのか」に分けて示す。
