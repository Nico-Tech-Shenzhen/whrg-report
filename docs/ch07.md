# 第7章　チーム・大学・メーカー・ロボット

大会の結果表に現れるチーム名を、そのまま企業名や機体メーカー名として集計すると関係を誤る。一つのチームに複数の大学・企業が参加することがあり、外部メーカーの機体を使うこともある。特定種目への出場は、チームそのものとも別の単位である。

## 五つの役割

| 役割 | 何を表すか | 混同すると起きる誤り |
|---|---|---|
| チーム | 大会で活動する参加集団 | 同名企業の全成果へ合算する |
| 出場枠 | あるチームの特定種目への登録 | 一出場を独立チームとして数える |
| 所属組織 | 大学、企業、研究機関 | 機体メーカーを自動的に所属先とする |
| 機体メーカー | ロボットを製造した主体 | 利用チームをメーカー直営とみなす |
| 支援・提供者 | 機体、訓練、資金、技術を提供する主体 | 支援から所有・成果帰属を推定する |

## 共通機体でも成果はチームに帰属する

5対5サッカーではBooster T2という共通機体が使われた。決勝結果は清華大学の<span lang="zh">清华火神队</span>の成果であり、メーカー単独の結果ではない。共通ハードウェアは比較条件を近づけるが、知覚、戦術、連携、調整はチーム側の仕事として残る。[[1]](#ref-1)

## 国際チームと中国製プラットフォーム

新華社によると、ブラジルのチームは五つのRoboCupチームを統合し、加速進化の機体と支援を受けた。豪州のRoboRoosは三大学の共同チームで、同社機体を使った。[[2]](#ref-2) これはメーカーの国外チームではなく、国外チームが中国製プラットフォームを開発基盤にした事例である。

日本のGMO RobotsはUnitree G1を二次開発し、100メートル、400メートル、1500メートルへ出場したと報じられた。[[3]](#ref-3) 早稲田大学との関係、宇樹科技の製造、G1の使用は、それぞれ別の関係として記述する。

## 大学・企業の共同チーム

公式結果には、北京人形ロボットイノベーションセンターと河南科技学院、北京舞蹈学院と智元、武漢大学と智元など、複数主体を名前に含むチームが現れる。[[4]](#ref-4) 公式名は参加主体の手掛かりになるが、契約、知的財産、開発担当、データ帰属までは示さない。

共同チームを単一企業へまとめないことは、メダル集計にもデータ公開にも重要である。「智元を含むチーム」と「智元という公式チーム名」は同じ集合ではない。同様に、ある機体を使ったことから、そのメーカーへメダルやデータを帰属させない。

## 関係が未確認なら空欄にする

名前の近さや同じ機体だけで組織関係を埋めると、後の分析が誤った前提を引き継ぐ。所属、製造、提供、共同参加は、公式結果、大学・企業発表、機体情報のいずれで確認したかを分け、確認できない関係は未確認のまま残す。
