# 第7章　そのデータは実際に使えるのか

「今日、WHRG 2026のデータを使いたい。どこから取得すればよいか」。2026年10月13日時点の答えは、監査した公式・公開資料から、第三者が再現できる公開取得経路を特定できない、である。規模と内容は発表され、社会へ無料開放するとの報道もあるが、ファイルへ至る安定した案内、取得手順、版、ライセンスを一続きに確認できなかった。[[1]](#ref-1)

## 7.1 利用者が到達できる段階

| 確認点 | 状態 | 利用者に必要なもの |
|---|---|---|
| データセットの発表 | 確認済み | 発表記事と規模説明 |
| 内容の説明 | 確認済み | 場面、作業、技能、収録内容の概要 |
| 公式ランディングページ | 未特定 | 配布物、版、利用条件をまとめた入口 |
| 申請・ダウンロード・API | 未特定 | 第三者がたどれる取得手順 |
| ファイル一覧 | 未特定 | マニフェスト、容量、分割、欠落確認 |
| 版と完全性 | 未特定 | リリースID、更新履歴、チェックサム |
| スキーマとサンプル | 未特定 | 読込み例、項目、単位、同期、注釈仕様 |
| ライセンス | 未特定 | 研究・商用利用、改変、再配布、引用条件 |

発表済みと取得可能は別の運用段階である。現状の公開情報だけでは、どの組織へ申請し、どの版を入手し、受け取ったファイルが発表された2,500時間超のどの部分かを照合できない。

## 7.2 「使える公開」に必要な構成

比較対象は、データ内容や品質の優劣ではなく、配布の仕組みを見るために選んだ。

| データセット | 入口と取得 | 構造・サンプル | 版・完全性 | 権利条件 |
|---|---|---|---|---|
| WHRG 2026大会データ | 発表記事まで。完全な取得経路は未特定 | 概要説明 | 未特定 | 未特定 |
| RoboMIND | データカード、同意後の配布 | 機体別軌跡、ファイル一覧、処理道具 | V1.0以後の更新説明 | Apache-2.0表示 |
| AgiBot World 2026 | データカードと取得例 | タスク別ファイル、サンプル | リポジトリ履歴と一覧 | CC BY-NC-SA 4.0 |
| Unitree公開データ群 | 公式組織からタスク別配布 | リポジトリごとの説明 | 各リポジトリ履歴 | 主にApache-2.0、個別確認 |
| WorldSimReady-Home | 配布ページ、試用版、同意制 | 家庭シーンと操作エピソード | ファイル一覧と試用版 | CC BY-NC-SA 4.0 |
| RekaDaily-10K | 登録不要の配布ページと手順 | 生・処理済みデータ、メタデータ | 件数と分割ファイルの更新 | Apache-2.0 |

RoboMINDは、同意が必要でも、データカードから内容、版、処理道具、取得手続へ進める。[[2]](#ref-2) AgiBot World 2026はタスク単位の取得例を示し、Unitreeは一つの巨大ファイルではなくタスク別リポジトリを公式組織下へ並べる。[[3]](#ref-3)[[4]](#ref-4) WorldSimReady-Homeは試用版を用意し、RekaDaily-10Kは人の一人称映像という異なる内容ながら、生データ、処理済みデータ、メタデータ、取得方法、ライセンスを一つの入口からたどれる。[[5]](#ref-5)[[6]](#ref-6)

共通しているのは、宣言の強さではなく、利用者が次の操作へ進めることだ。

1. 固有の公開ページを開く。
2. 対象リリースと必要なファイルを選ぶ。
3. 取得手順を実行する。
4. マニフェストやチェックサムで完全性を確かめる。
5. スキーマとサンプルで読み込む。
6. ライセンスに従って利用・引用する。

WHRGデータに必要なのも、この運用列である。最初の有効な公開は、別の発表記事ではなく、少なくともサンプルを取得し、版、構造、権利条件まで追える入口によって確認できる。

## 7.3 現在の到達点

WHRGは、競技を越えて再利用したいデータの規模と内容を具体的に示した。一方、利用者側から見ると、現時点の成果は「発表・内容説明」の段階にある。公開状態が変わったときは、案内ページの有無だけでなく、第三者環境からの取得、マニフェストとの照合、版・チェックサム・スキーマ・ライセンスの保存をもって更新を判定する。

この区別により、2,500時間超という技術的可能性を過小評価せず、同時に「無料開放」という表現だけで利用可能とみなすことも避けられる。大会成果を継続的な研究基盤へ変える最後の工程は、ファイルを外部利用者まで届ける出版設計である。
