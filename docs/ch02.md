# 第2章　51競技で何を競ったか

30の競技部門は、速く動くだけでなく、曲がる、止まる、相手へ反応する、複数機で同期する、物体へ適切な力を加える能力を別々の規則で測った。本章は代表種目を開始から終了まで追い、最後に実環境タスクを含む全51種目の見取図を示す。[[1]](#ref-1)

## 2.1 陸上競技：走り出す、曲がる、止まる

100メートル走では、ロボットはスタート位置に静止し、チームから一度だけ開始指令を受ける。その後は人が進路を修正せず、機体が加速し、レーンを保ち、ゴール線を越え、減速する。順位は完走時間で決まる。大型級決勝の8.64秒は速さの記録であると同時に、ゴール後に姿勢を崩さず止まる制動も設計課題にした。[[2]](#ref-2)[[3]](#ref-3)

400メートル走は直線だけでなくカーブを含む一周で、姿勢制御を長く維持する。1500メートル走はさらに周回を重ね、全力に近い運動を2分以上続ける。100メートルの完走上限は1分、400メートルは5分、1500メートルは15分へ短縮され、障害走を除く陸上競技は完全自律が要求された。2026年の1500メートル優勝記録は2分21秒64だった。[[2]](#ref-2)[[4]](#ref-4)

障害走は、ロボットが段差や障害物を認識して越える一方、規則上の限定補助が認められた。速度種目に地形認識と足の置き場の選択を加えた競技である。

## 2.2 サッカー：10台の認識と判断を同時に動かす

5対5大型サッカーでは、両チームの5台ずつ、計10台が同時にフィールドへ入る。大型級は共通機体Booster T2を使い、試合中の遠隔操作はない。ロボットはボール、ゴール、味方、相手を認識し、移動、パス、ドリブル、シュートを自ら選ぶ。2026年にはゴールキック、コーナーキック、スローインが加わり、再開局面への対応も必要になった。試合は得点で決まり、決勝は清華大学<span lang="zh">清华火神队</span>がSPQRに10対1で勝った。[[5]](#ref-5)[[6]](#ref-6)

3対3 U19は同じ自律対戦を青少年チーム向けに小さな編成で行う。卓球では、球の軌道を短時間で予測し、移動とラケットの振りを合わせる。球技群は、単機の決められた動作ではなく、相手によって変わる状況での知覚と判断を採点する。

## 2.3 格闘・力競技：接触と力を勝敗へ変える

キックボクシングは40、58、80キログラム級の全自律対戦で、ポイント判定、ノックアウト、レフェリーストップによって勝敗を決めた。機体が相手を見つけ、間合いを取り、打撃し、転倒後の状態へ対応する。単に「判定で勝敗を決める」のではなく、同じ競技面で二機が互いの動きに反応する接触競技である。[[7]](#ref-7)

重量挙げは、ロボットがバーベルを握って持ち上げ、規定時間保持できた最大重量を競う。重量級では基準のバーへ段階的に重りを加え、16キログラムの成功が優勝記録になった。綱引きはロープ中央の目印を自陣側へ動かす複数ラウンド制で、腕の力だけでなく、足裏の摩擦、重心、姿勢保持が結果を左右した。[[8]](#ref-8)[[9]](#ref-9)

## 2.4 体操・ダンス・武術：動作を演技として採点する

床運動は、20を超える候補から10動作を選び、走る・跳ぶなどのつなぎ動作を含む一つの演技として実行した。個々の空翻や転回ができるだけでなく、動作間を滑らかにつないで終えることが必要だった。[[10]](#ref-10)

ダンスはストリートダンス、標準舞、チアダンスに分かれる。標準舞は2台でワルツまたはサンバを踊り、チアダンスは花球を持つ最大12台の隊形変化を含む。全て完全自律で、9人の審査員が採点し、最高点と最低点を除いた平均を用いた。評価対象は運動制御、複数機協調、振り付けである。[[11]](#ref-11)

## 2.5 デクスタラスハンド：指先と工具を使う

8種のデクスタラスハンド専門種目は、対象物と接触条件を変えて手先を試した。粉末計量では、スプーンで粉をすくい、電子秤の表示が20グラム±0.5グラムへ入るまで量を調整する。優勝走行は27秒だった。電動工具組立では、ネジを拾い、ドライバーを穴へ合わせ、実物の工具シェルへ締める。優勝チームは完全自律で5分間に18本を締め、17本を得点対象にした。[[12]](#ref-12)[[13]](#ref-13)

ピンセット豆つかみは約5ミリメートルの豆を道具越しにつまみ、ケーブル接続は動かすたび形が変わる線材を位置合わせして端子へ挿す。速い腕振りではなく、視覚、指先位置、力加減を閉ループで合わせる競技である。

## 2.6 実環境タスク：能力を仕事へ組み直す

実環境タスク部門では、ここまでの移動、把持、姿勢制御、道具使用を、一つの仕事の順序へ組み直した。オフィスなら、会議用品の配置、プリンターへの給紙、書類の配達、廃棄文書の裁断までを設備ごと切り替える。[[14]](#ref-14) 21種目の課題と結果は[第3章](ch03.md)で扱う。
