# WHRG 2026：人型ロボット競技の全体像と記録

世界人型ロボット競技大会（公式英語名：World Humanoid Robot Games、略称WHRG）は、人型ロボットだけを競技主体とする国際大会である。第2回大会は2026年8月22日から26日まで、北京の国家速滑館「アイスリボン」を主会場に開かれた。主催は北京市人民政府、中央広播電視総台（CMG）、世界ロボット協力機構、RoboCup Asia-Pacific Confederation Board of Trustees（RCAP）の4者である。[[1]](#ref-1)[[2]](#ref-2)

六大陸16か国から666チーム、2,056台のロボットが集まり、5日間に51種目、1,301試合・試技を実施した。国内参加だけでも157社と200の大学・研究機関を含む。速さや跳躍を測る陸上、10台が同時に判断するサッカー、工場・家庭・ホテル・消防などの仕事、指先と工具を使う作業が、一つの大会で別々の規則と評価軸を持った。[[3]](#ref-3)

観戦は午後と夜の有料セッションとして一般に開かれた。『人民公安報』は、会期中に1万人を超える観客が来場したと報じている。ただし、実人数・延べ人数など集計方法は示されていない。主催者が認定した来場者総数ではなく、出典を伴う報道値として扱う。[[4]](#ref-4)[[5]](#ref-5)

本報告が問うのは、どのロボットが勝ったかだけではない。51種目は人型ロボットのどの能力を測り、チーム、機体、訓練設備、規則はその比較をどう支えたのか。大会後に発表された2,500時間超のデータは、第三者が実際に使える成果になっているのか。競技の具体像から結果、技術基盤、データ公開までを一続きの技術・イベント報告として検証する。

## 読み進め方

[第1章](ch01.md)で会場、参加者、51種目の構造、自律と遠隔操作を整理する。[第2章](ch02.md)と[第3章](ch03.md)では、ロボットが開始から終了まで何をしたかを競技と実作業に分けて追う。[第4章](ch04.md)は記録とメダルから性能の意味を読み、[第5章](ch05.md)はチーム、機体、訓練・整備基盤の関係を示す。[第6章](ch06.md)と[第7章](ch07.md)は発表されたデータの内容と利用可能性を分けて検証し、[第8章](ch08.md)で初年度からの変化と大会後の展開を考える。全結果、調査方法、未解決点は[付録](appendix.md)に置く。
