# Terminology authority

Public prose uses the canonical Japanese form. Source forms may appear only in references, direct quotations, URLs or code identifiers, marked official team names, and a useful first-use official-name annotation. `Not Found` means that an authoritative official English form was not verified; it must not be replaced by an invented translation. The Forbidden column is machine-readable and uses semicolon-separated alternatives.
